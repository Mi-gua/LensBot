# DeepLens 优化经验

## 确认经验

- 当目标为复杂标准镜头（如 >6 片且含非球面）但候选库仅提供简单结构（如单透镜、双胶合）时，避免强行选择简单种子；应优先触发种子扩充或回退至经典复杂拓扑（如 Double Gauss），因为简单拓扑无法承载目标光焦度，必然导致一阶灾难性漂移。
- 当 curriculum 阶段一阶参数极其稳定（如漂移 <0.01%）但最终边缘画质较差（如边缘 RMS spot 大、MTF 低）时，避免盲目增加 fine-tune 迭代；应优先调整 asphere 系数或修改种子结构（如增加后组 asphere 自由度），因为当前种子拓扑缺乏足够的像差校正潜力。
- 当设计中等 FOV（如 40°-50°）的标准焦段镜头时，优先选择 Double Gauss 类结构以保证一阶收敛稳定性，但必须确保后组具备足够的 asphere 自由度以校正残余边缘像差。
- 当使用极小迭代次数（如 10 次）进行 smoke test 时，避免将 checkpoint 的微小一阶漂移视为收敛依据；这常呈现虚假稳定，全量预算下仍会暴露严重的一阶偏移和边缘画质崩溃。
- 当 curriculum 阶段一阶稳定，但 fine-tune 引发 F/# 或 EFL 严重漂移时，必须立即 rollback 至最佳 checkpoint 并提高一阶锁定权重，避免在发散状态上浪费迭代预算。
- 当使用结构修改工具（如 asphere 转 spheric）或调用终止工具（如 `finish`）时，避免盲目猜测参数或附加非标准字段；应先 inspect 种子确认面型分布，并严格遵循工具 schema 定义，以防止触发工具报错或校验失败。

## 弱信号

- 当多个相似种子变种（如不同玻璃搭配的 Double Gauss）收敛结果的一阶均稳定但边缘画质均无法提升时，表明已触及该结构极值；应停止同类重试，优先更换完全不同的种子结构以打破局部最优。
- 当优化器在简单种子上强行增加面数仍无法收敛一阶时，表明种子拓扑本身不具备该光焦度分配潜力；应尽早放弃并更换种子，避免浪费计算预算。
