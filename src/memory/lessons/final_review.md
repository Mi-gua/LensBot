# 整体验证与通用镜头经验

## 经验条目

- 当设计中等视场（40°-50°）标准镜头时，优先选择 Double Gauss 类结构，其对标准焦段更稳，但后组非球面提供的优化自由度更为关键。
- 当优化 Double Gauss 等经典结构时，避免依赖增加面数来挽救一阶漂移；优化器极易陷入局部极小值导致 EFL/FOV 发生翻倍或减半级别的灾难性偏离，必须在早期严格锁定一阶光焦度分配。
- 当优化中等 F/#（如 F/2.8-F/4）镜头时，即使 EFL 和 FOV 完美收敛，F/# 仍可能发生严重漂移（>15%）；必须在优化早期将 F/# 或入瞳直径作为硬性约束锁定，避免优化器通过改变光阑前后光焦度分配来牺牲 F/#。
- 当跨引擎验证（DeepLens 与 Zemax）发现 EFL/FOV 一致但 F/# 存在巨大差异（如 >15%）时，通常表明入瞳位置计算或光阑前后光焦度分配存在根本性分歧；需重新平衡光焦度并严格约束入瞳直径。
- 当自动化流程标记设计为 `accepted` 但一阶属性（特别是 F/#）严重偏离目标（如 >5%）时，必须无视该标签并强制拦截；自动化验收无法替代对 F/# 等关键物理属性的合理性检查。
- 当 Double Gauss 结构在中等 F/# 下边缘像差（RMS/MTF）达到物理瓶颈时，避免在边缘过度优化导致整体结构崩溃；应优先保证中心视场质量并控制畸变，或考虑引入更多非球面/改变拓扑。
- 当优化过程中 EFL 和 FOV 发生严重偏离（如偏离目标 >50%）时，避免仅微调边界或强行增加面数；应彻底重构一阶约束和种子缩放比例，打破崩溃的结构。
- 当设计大视场（>60°）且需要较长后截距的广角镜头时，优先选择反远距（Retrofocus）结构，并确保前组具有足够的负光焦度。
- 当 Zemax 不可用时，应将其视为验证环节的 caveat 而非光学设计失败的证明，但需明确标注一阶属性及边缘性能可能存在偏差。
